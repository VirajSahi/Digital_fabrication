<div class="textcontainer"> <p class="margin"> </p> <h3>Week 6: Electronic Inputs</h3> <h4 style="text-align:center"><u>Intro</u><h4><br> <h5>This week’s assignment was enjoyable yet tedious. I created/measured 5 sensors, 3 of which I made myself using capacitance. These 5 were: </h5> <ul> <li>A hall sensor measuring the <b>distance</b> between sensor and magnet</li> <li>A hall sensor measuring the <b>number of magnets</b> placed at a fixed distance</li> <li>A capacitance-based <b>distance</b> sensor</li> <li>A capacitance-based <b>salinity</b> sensor for salt-water solutions</li> <li><b>Fruit finder</b>: A capacitance-based sensor that identifies chunks of fruit</li> </ul> <h5>For each of these, I collected data via <b>google sheets</b> and plotted valiues and uncertainties on <b>LoggerPro</b><br><br><br> <h4 style="text-align:center"><i><b>Assignment 1: Capactive Sensor</b></i><h4> <h4 style="text-align:center"><u>Hall sensor measuring distance</u><h4><br> <div style="display: flex; align-items: flex-start; gap: 20px;"> <div style="flex: 1;"> <h5> I used a Hall sensor to measure magnetic field strength with my ESP32-C3 microcontroller. First, I connected the sensor’s analog output to an ADC pin and powered it using 3.3V and GND. Then, I wrote a program that repeatedly read analog values and printed the results into the serial monitor. Moving the magnet close to the sensor caused a spike in the readings. To increase sensitivity, I averaged multiple readings in a loop. Initially, the sensor was affected by interference from metallic/electronic materials in the lab, so I moved my apparatus to the library where there was lesser noise, and the sensor performed much more reliably. On the side is a photo of my setup and below is a snippet of my code: </h5> <pre style="font-size: 16px;"><code class="cpp"> int analog_pin = A3; void setup() { Serial.begin(115200); } void loop() { long sum = 0; int N_samples = 100; for (int i = 0; i < N_samples; i++) { sum += analogRead(analog_pin); } long average = sum / N_samples; serial.printl(average); delay(100); } </code></pre> </div> <div style="flex: 1;"> <img src="MagnetHall1.jpg" alt="Hall Sensor Setup" style="width: 500px; height: auto; border: 1px solid #ccc;"> </div> </div> <br> <h5> I positioned the magnet at a minimum of 1 cm (getting the largest possible deviation), and a maximum of 35 inches (where the reading was close to negligible). With every reading, I moved the magnet further away by increments of 1 cm, and took the mean of 35 randomly selected values produced by the serial monitor. I then calculated the absolute and relative uncertainties. Lastly, I graphed the data on logger pro with the uncertaities and found the line of best fit in the form 'y = A*(1 - exp(-B*x)) + C' (asymptotic exponential growth). The correlation was 0.9929!
