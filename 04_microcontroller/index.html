As someone who's never coded or touched a circuit before, and whose expertise with solving tech-related problems is limited to angrily turning off and on power buttons, Arduino was challenging, yet fun. My aim was to program the microcontroller to use in my kinetic sculpture. I wanted to have lights behind the apple whose brightness increases as the hand approaches it. I started with the code for just one: <h5> <pre><code class="cpp"> const int trigPin = 19; const int echoPin = 18; const int ledPin = 9; const int freq = 5000; const int pwmChannel = 0; const int resolution = 8; unsigned long lastSensing = 0; const unsigned long timeInterval = 100; float duration, distance; int ledVal; void setup() { pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); pinMode(ledPin, OUTPUT); ledcAttach(ledPin, freq, resolution); Serial.begin(9600); } void loop() { if (millis() - lastSensing >= timeInterval) { lastSensing = millis(); digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); duration = pulseIn(echoPin, HIGH); distance = (duration * 0.0343) / 2; ledVal = map(distance, 5, 40, 255, 0); ledVal = constrain(ledVal, 0, 255); ledcWrite(ledPin, ledVal); Serial.print("Distance: "); Serial.print(distance); Serial.println(" cm"); } } </code></pre> <h5>This worked! WOohoOOo!!!
